# Meesho E-Commerce Storefront Clone 🛒

A clean, responsive, high-performance E-Commerce Web Application replicating modern Meesho features, styled with a modern glassmorphic dark theme interface.

## 🚀 Key Features

* **Dynamic Catalog & Filtering:** Search products by keyword, sort by price (Low to High / High to Low), and filter by categories or Free Delivery tags.
* **Interactive Cart Drawer:** Slide-out slide drawer displaying items, dynamically calculating totals, and removing items in real time.
* **State Persistence:** LocalStorage integration to save user cart items across page reloads.
* **Responsive Layout:** Optimized across mobile, tablet, and desktop display resolutions.

## 🛠 Tech Stack

* **HTML5:** Semantic structural setup.
* **CSS3:** Custom CSS Variables, Flexbox, CSS Grid layout patterns.
* **Vanilla JavaScript:** Event-driven dynamic DOM manipulation and state sync.
